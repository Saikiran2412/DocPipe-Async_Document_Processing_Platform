    How it works

    1. The API creates a job row and returns a presigned upload URL.
    2. Your browser uploads straight to object storage.
    3. Start queues the job in RabbitMQ and returns 202.
    4. A worker runs validate, parse (OCR if needed), extract, summarize.
    5. Progress streams back live (Redis pub/sub and SSE).
    6. Transient errors retry with backoff, then dead-letter.
    7. An optional signed webhook announces the result.
